# Contributing

Open an issue before changes that alter behavior so the approach can be agreed.
Keep pull requests focused, follow the setup instructions in the README, and
add or update tests and documentation for behavior changes.

Before review, run `python -m pytest` from a clean checkout. Pull requests must
link their issue, describe validation, and call out user-visible, operational,
security, privacy, or compatibility impact. Do not include secrets, credentials,
personal data, or internal-only details.
