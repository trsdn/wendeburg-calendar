# Security Policy

## Supported versions

The current default branch and latest release are supported. Older releases are
not patched unless stated otherwise.

## Report a vulnerability privately

Use this repository's **Security** tab and choose **Report a vulnerability**.
If private reporting is unavailable, open an issue asking for a private channel
without including exploit details.

Include the affected commit or release, realistic impact, minimal reproduction,
and a suggested fix when available. Do not disclose details publicly before a
fix is available, and never include credentials, tokens, or personal data.

## What to expect

Reports are triaged privately. Confirmed issues are addressed on a timeline
that matches their severity, and reporters are credited on request after a fix
ships.
